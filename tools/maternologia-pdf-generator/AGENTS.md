# Instruções locais

- Este repositório gera somente os dois PDFs do produto 100 Dias Sem Caos.
- `content/content.md` é a fonte editorial canônica e não deve ser reescrita.
- Decisões conservadoras devem ser registradas em `DECISIONS.md`.
- Toda escrita operacional deve permanecer dentro deste diretório.
- Um build com falha não deve substituir os PDFs existentes em `outputs/`.
- Não adicionar rede, telemetria, imagens editoriais, JavaScript ou XFA.
